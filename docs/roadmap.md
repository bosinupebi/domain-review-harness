# Roadmap

The current focus is a dependable self-hosted review workflow. Future work is proposed, not promised:

- Exact-host allowlists, explicit discovery controls, and configurable check profiles.
- Request budgets, rate controls, and a total review deadline.
- A versioned results schema and richer remediation guidance.
- Dependency/license review and packaged releases before public launch.
- More fixtures for false positives, redirects, and incomplete checks.

Public release requires a deliberate visibility change by the owner. The repository remains private until then.
